# Pace support

For installation questions, bug reports, privacy questions or feedback, [open an issue](https://github.com/kyleisbased/pace/issues/new) in this repository. Issues are public: do not include passwords, tokens, email addresses, private usage history or screenshots containing personal data. Share only the operating system, Pace version, a non-sensitive error message and steps to reproduce.

## Before reporting a problem

Check that Node.js 22+ and Codex CLI are installed, and that Codex CLI is signed in with your ChatGPT account. API-key-only accounts do not provide the subscription usage windows Pace needs.

Ask Codex to **Start Pace** and open the returned local dashboard address. If it is already running, the existing instance is reused. Ask **Stop Pace** to stop tracking. A sleeping or offline computer cannot record fresh usage.

If a new installation is not visible, restart the desktop app and open a new local chat. The plugin does not work in a cloud-only or phone-only conversation.

To remove saved data, stop Pace first, then remove its data directory and clear the local dashboard's browser site data. [Privacy policy](PRIVACY.md) lists the default locations. Uninstalling alone does not erase history.

Support is handled through this repository; no response-time commitment is offered.
